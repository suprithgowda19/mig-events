# MIG Events & Productions

> Experiential & Live Stage Productions

Turnkey experiential event management and live stage production in India — corporate summits, luxury weddings, arena concert sound engineering, and German hangars.

## 🌐 Live Website

- **Live URL**: [https://suprithgowda19.github.io/mig-events/](https://suprithgowda19.github.io/mig-events/)

## 🛠 Tech Stack

- **HTML5 & Modern CSS**
- **Tailwind CSS** (via CDN)
- **Vanilla JavaScript** (Animations & Interactions)
- **Lucide Icons**

## 📂 Project Structure

```text
├── assets/          # Media, images, and manifest files
├── content/         # Page content and source data
├── css/             # Custom styling
├── js/              # Interactive logic and motion graphics
├── scripts/         # Asset management and utility scripts
├── index.html       # Main landing page
└── README.md
```

## 🚀 Local Development

Simply open `index.html` in any modern web browser or serve via a local HTTP server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js npx
npx serve .
```
